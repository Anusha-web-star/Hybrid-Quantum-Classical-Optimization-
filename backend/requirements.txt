# Assistant (RAG) - no package required.
#
# Generation runs on a LOCAL model through Ollama, reached with one POST to
# 127.0.0.1 using `urllib` from the standard library. There is no API key, no
# account, no per-token cost, and no cloud SDK: the GRIDOPT dataset, solver
# results and documents never leave this machine.
#
# Ollama itself is the only prerequisite, and it is not a Python package:
#   https://ollama.com/download   then:   ollama pull llama3.2:3b
#
# Retrieval needs no extra package either: it is BM25 computed in process over
# the project's own chunks. See backend/app/assistant/retrieval.py for why this
# is not pgvector.
